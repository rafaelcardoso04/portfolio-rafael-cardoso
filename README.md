# Portfólio — Rafael Cardoso

Portfólio pessoal de apresentação, com minha formação, tecnologias, projetos e pretensões profissionais. Desenvolvido com HTML5, CSS3 e JavaScript puro, com tema visual inspirado no "Mundo Invertido" de Stranger Things.

🔗 **Acesse:** https://github.com/rafaelcardoso04/portfolio-rafael-cardoso

## Sobre

Formado em Gestão da Tecnologia da Informação, com base em redes, Linux e desenvolvimento web. Este portfólio reúne meus projetos e objetivos: atuar como analista de dados e cursar pós-graduação em Ciência de Dados.

## Tecnologias

- HTML5
- CSS3 (variáveis, animações, clamp, flexbox)
- JavaScript (Canvas API)
- SVG
- Git e GitHub Pages

## Destaques

- Título em neon com animação de lâmpada falhando
- Fundo com névoa animada em camadas
- Partículas (esporos) e relâmpagos ramificados desenhados em Canvas
- Ilustração vetorial em SVG no rodapé
- Layout responsivo
- Acessibilidade: `prefers-reduced-motion`, foco visível e `aria-hidden` nos elementos decorativos

## Estrutura

```
/
└── index.html   # HTML, CSS e JavaScript em um único arquivo
```

## Como executar localmente

1. Clone o repositório:
   `git clone https://github.com/rafaelcardoso04/portfolio-rafael-cardoso.git`
2. Abra o arquivo `index.html` no navegador.

Opcionalmente, sirva localmente com Python:
`python -m http.server 8000`
e acesse `http://localhost:8000`.
